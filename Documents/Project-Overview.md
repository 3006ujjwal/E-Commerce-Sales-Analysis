# Project Overview

## Project Title

E-Commerce Sales Analysis

## Objective

The objective of this project is to analyze e-commerce sales data and develop an interactive dashboard using Microsoft Power BI.

The analysis focuses on understanding sales performance, profitability,
product performance, retailer performance, regional trends, and sales methods.

## Business Questions

The project aims to answer questions such as:

1. What is the overall sales performance?
2. How much operating profit is generated?
3. Which products perform best?
4. Which retailers generate the highest sales?
5. Which regions perform best?
6. How do sales change over time?
7. Which sales methods contribute the most to revenue?

## Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel
- Git
- GitHub

## Project Workflow

1. Import the sales dataset into Power BI.
2. Clean and transform the data using Power Query.
3. Build the data model.
4. Create calculated measures using DAX.
5. Design interactive dashboards.
6. Analyze the results.
7. Document the key findings.
