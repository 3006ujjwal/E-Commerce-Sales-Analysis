# Data Dictionary

This document describes the fields available in the Adidas sales dataset
used for the E-Commerce Sales Analysis Power BI project.

| Column | Description | Data Type |
|---|---|---|
| Retailer | Name of the retailer through which the product was sold. |Text |
| Retailer ID | Unique identifier associated with the retailer. | Integer |
| Invoice Date | Date associated with the sales transaction/record. |Date |
| Region | Geographic region in which the sale occurred. | Text |
| State | U.S. state associated with the sale. | Text |
| City | City associated with the sale. | Text |
| Product | Adidas product category/type. | Text |
| Price per Unit | Selling price for one unit of the product. | Numeric |
| Units Sold | Number of units sold in the record. | Integer |
| Total Sales | Total revenue generated by the record. | Numeric |
| Operating Profit | Operating profit generated by the record. | Numeric |
| Operating Margin | Operating profit expressed as a proportion of total sales. | Decimal |
| Sales Method | Sales channel/method used for the sale. | Text |

## Data Coverage

The dataset contains sales information across:

- Retailers
- Products
- Regions
- States
- Cities
- Sales methods
- Invoice dates
